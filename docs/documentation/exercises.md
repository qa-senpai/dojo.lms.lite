# Як створити quiz або JavaScript-задачу

Увійдіть як адміністратор, відкрийте потрібний курс і розділ. У блоці **Вправи** розгорніть **Нова вправа**. Для обох типів введіть **Назву вправи** (2–180 символів) та **Умову** (1–10 000 символів).

Нижче наведено повні JSON-приклади для створення однієї вправи через `POST /api/courses/:courseId/chapters/:chapterId/exercises`. У формі редактора перенесіть значення в окремі поля. Для полів із позначкою JSON копіюйте відповідний масив разом із квадратними дужками.

## Quiz з однією правильною відповіддю

Виберіть тип **Тест**. В умові поставте одне запитання. У поле **Варіанти тесту** вставте масив із 2–8 непорожніх рядків завдовжки до 1000 символів кожен. У полі **Правильна відповідь тесту** вкажіть індекс правильного варіанта. Відлік починається з нуля, тому в цьому прикладі `1` означає другий варіант — `"3"`.

```json
{
  "title": "Довжина масиву",
  "kind": "QUIZ",
  "prompt": "Яке значення має [4, 0, 8].length?",
  "options": ["2", "3", "8"],
  "answer": 1
}
```

## JavaScript-задача з автоматичною перевіркою

Виберіть тип **JavaScript**. В умові опишіть аргументи функції та значення, яке вона має повернути. У поле **Стартовий JavaScript — функція solve** введіть заготовку функції як звичайний код, наприклад `function solve(numbers) { /* Ваш код */ }`. У поле **Тести JavaScript (JSON)** скопіюйте масив із поля `tests`.

```json
{
  "title": "Сума елементів масиву",
  "kind": "CODE",
  "prompt": "Поверніть суму чисел у масиві numbers. Для порожнього масиву поверніть 0.",
  "starter": "function solve(numbers) { /* Ваш код */ }",
  "tests": [
    { "input": [[2, 3, 4]], "expected": 9 },
    { "input": [[]], "expected": 0 },
    { "input": [[-5, 2]], "expected": -3 }
  ]
}
```

Кожен тест викликає `solve(...input)` і порівнює повернене значення з `expected`. Зовнішні дужки в `input` позначають список аргументів. Тому `[[2, 3, 4]]` викликає `solve([2, 3, 4])`, а `[2, 3]` у задачі з двома параметрами викличе `solve(2, 3)`. Так само `[[]]` передає порожній масив, а `[]` викликає функцію без аргументів.

Додайте від 1 до 30 тестів, до 10 аргументів у кожному. Використовуйте JSON-значення для аргументів і очікуваного результату. Тип значення та порядок елементів масиву мають значення. Ключі об’єкта можуть іти в будь-якому порядку. На виконання всього набору відведено 5 секунд.

## Як перевірити вправу

Натисніть **Додати вправу**, потім **Переглянути розділ** і відкрийте вкладку **Вправи**. Для quiz перевірте правильний і хибний варіанти. Для JavaScript-прикладу спробуйте рішення з `return numbers.reduce((sum, n) => sum + n, 0)`, а потім замініть його на `return 0` і перевірте, які тести виявили помилку. Зміна збереженої вправи скидає попередні результати студентів для цієї вправи.

Цей формат можна взяти за основу для власного skill. Наприклад, за умовою задачі й підготовленими тестовими даними він може генерувати масив `tests` для вставлення в редактор. Перед збереженням звірте кожне `expected` з умовою.
